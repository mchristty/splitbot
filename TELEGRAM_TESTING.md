# 📱 Тестирование бота через Telegram UI

## 🚀 Быстрый старт

### 1. Найти бота в Telegram

- **Имя бота:** `@splitnofsfgdbsdf_bot`
- **ID бота:** `8301851864`
- **Название:** Splitwise_bot

### 2. Запустить бота

```bash
make dev
```

### 3. Начать тестирование

Отправьте `/start` боту в Telegram

## 🧪 Пошаговое тестирование функций

### Шаг 1: Базовые команды

#### Тест команды `/start`

```
/start
```

**Ожидаемый результат:** "Привет! Я помогу вам записывать все траты"

#### Тест команды `/help`

```
/help
```

**Ожидаемый результат:** Список всех доступных команд

### Шаг 2: Создание группы

#### Создать тестовую группу

```
/create [Тестовая группа]
```

**Ожидаемый результат:** "Группа Тестовая группа успешно создана"

#### Проверить список групп

```
/show
```

**Ожидаемый результат:** "Список групп: \nТестовая группа"

### Шаг 3: Добавление участников

#### Добавить себя в группу

```
/add [Тестовая группа] [@ваш_username]
```

**Ожидаемый результат:** "Юзер успешно добавлен в группу"

#### Добавить еще одного участника (если есть)

```
/add [Тестовая группа] [@другой_пользователь]
```

### Шаг 4: Тестирование платежей

#### Добавить трату

```
/payment [Тестовая группа] [@ваш_username] [100]
```

**Ожидаемый результат:** "Баланс успешно изменен"

#### Проверить балансы

```
/show [Тестовая группа]
```

**Ожидаемый результат:** Список балансов между участниками

## 🔍 Тестирование сценариев

### Сценарий 1: Простое разделение расходов

1. **Создать группу:**

   ```
   /create [Поездка в отпуск]
   ```

2. **Добавить участников:**

   ```
   /add [Поездка в отпуск] [@alice]
   /add [Поездка в отпуск] [@bob]
   /add [Поездка в отпуск] [@charlie]
   ```

3. **Записать траты:**

   ```
   /payment [Поездка в отпуск] [@alice] [1000]
   /payment [Поездка в отпуск] [@bob] [500]
   /payment [Поездка в отпуск] [@charlie] [300]
   ```

4. **Проверить балансы:**
   ```
   /show [Поездка в отпуск]
   ```

### Сценарий 2: Семейные расходы

1. **Создать группу:**

   ```
   /create [Семейный бюджет]
   ```

2. **Добавить членов семьи:**

   ```
   /add [Семейный бюджет] [@мама]
   /add [Семейный бюджет] [@папа]
   /add [Семейный бюджет] [@сын]
   ```

3. **Записать покупки:**
   ```
   /payment [Семейный бюджет] [@мама] [2500]
   /payment [Семейный бюджет] [@папа] [1800]
   /payment [Семейный бюджет] [@сын] [1200]
   ```

## 🔧 Отладка проблем

### Проблема: Бот не отвечает

1. Проверьте статус: `make status`
2. Посмотрите логи: `make logs`
3. Перезапустите: `make restart`

### Проблема: Ошибки в базе данных

1. Запустите тесты: `make test`
2. Очистите данные: `make clean`
3. Перезапустите бота: `make restart`

### Проблема: Конфликт экземпляров

1. Остановите все: `make stop`
2. Подождите 5 секунд
3. Запустите заново: `make dev`

## 🎯 Рекомендации по тестированию

1. **Начните с простых команд** - `/start`, `/help`
2. **Создайте тестовую группу** с понятным названием
3. **Добавьте себя** как участника
4. **Протестируйте платежи** с разными суммами
5. **Проверьте балансы** после операций
6. **Тестируйте ошибки** - неправильные команды
7. **Очищайте данные** после тестов: `make clean`

## 🚨 Важные замечания

- **Всегда используйте квадратные скобки** `[название]` для параметров
- **Используйте @username** для участников
- **Суммы вводятся как числа** без валюты
- **Группы привязаны к чату** - в разных чатах разные группы
- **Очищайте тестовые данные** после тестирования
