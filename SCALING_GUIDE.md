# 🚀 Руководство по масштабированию бота

## 🔧 Оптимизации базы данных

### ✅ Пул соединений

- **20 базовых соединений** в пуле
- **30 дополнительных** при пиковой нагрузке
- **Автоматическая проверка** соединений
- **Переиспользование** соединений каждый час

### ✅ Индексы для быстрого поиска

```sql
-- Индексы для таблицы Group
CREATE INDEX idx_group_chatid ON "Group" ("ChatId");
CREATE INDEX idx_group_name ON "Group" ("GroupName");

-- Индексы для таблицы GroupUser
CREATE INDEX idx_groupuser_groupid ON "GroupUser" ("GroupId");
CREATE INDEX idx_groupuser_userid ON "GroupUser" ("UserId");

-- Индексы для таблицы BalanceUserToUser
CREATE INDEX idx_balance_groupid ON "BalanceToUser" ("GroupId");
CREATE INDEX idx_balance_firstuser ON "BalanceToUser" ("FirstUserName");
CREATE INDEX idx_balance_seconduser ON "BalanceToUser" ("SecondUserName");
CREATE INDEX idx_balance_composite ON "BalanceToUser" ("GroupId", "FirstUserName", "SecondUserName");
```

## 🎯 Конфигурация масштабирования

### ✅ Настройки в `scaling_config.py`

```python
DATABASE_CONFIG = {
    'pool_size': 20,        # Базовые соединения
    'max_overflow': 30,     # Дополнительные соединения
    'pool_pre_ping': True,  # Проверка соединений
    'pool_recycle': 3600,   # Переиспользование (1 час)
}

BOT_CONFIG = {
    'max_concurrent_users': 1000,  # Максимум пользователей
    'rate_limit_per_user': 10,     # Лимит запросов/минуту
    'session_timeout': 3600,       # Таймаут сессии (1 час)
}
```
